# Seven Stories of Hope

A step-by-step Discovery Bible Study guide (SWORD method) for Jeff Sundell's *Seven Stories of Hope*. Anyone can lead a group with it: open the site on one phone or screen and tap through Looking Back, Looking Up and Looking Ahead. Scripture loads live from the ESV API.

## Connecting the ESV Bible

1. Create a free key at https://api.esv.org/account/create-application/
2. Either paste it into **ESV settings** in the app (saved only in that browser), or
3. Edit `index.html`, find `const ESV_API_KEY = "";` near the top of the script, and paste the key between the quotes so everyone who opens the site gets passages automatically. Anyone can see a key placed there, so use a key made only for this site.
